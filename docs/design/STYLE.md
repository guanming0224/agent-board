# Claude 控制中心（Agent Board）— 設計邏輯與風格「塔台 × 放手線」

> 適用：`packages/web` 的所有畫面。
> 可以直接打開看的範例：同資料夾 `style-sample.html`（單一檔、零外部套件）。Token 實作：`packages/web/src/shared/styles/tokens.css`。
> 基底是一套高對比深色規範，本文件已列出實作需要的差異；背景、文字、間距與圓角的數值見 `tokens.css` 與範例。

---

## 0. 一句話

**這是一座塔台：你不是在看十個終端機，你是在決定下一個該處理誰。最大的數字永遠是「幾個在等你」；顏色只回答「球在誰手上」；每張卡左邊的線型回答「你放手了多少」；終端機裡面的顏色是 Claude Code 的，我們一筆都不碰。**

兄弟介面各自要防的東西：

| 介面 | 要防的 | 主角 |
|---|---|---|
| 海龜訊號 | 虧錢、誤下單 | 帳戶權益 |
| 策略驗證平台 | 自欺 | 通過關卡的策略數 |
| tw-quant | 把未驗證的訊號當依據 | 已放行策略數 |
| 美股量化平台 | 偷看未來資料 | 通過 G1–G6 的策略數 |
| 外匯模組 | 以為分散了其實全押同一貨幣 | 開倉許可 |
| 加密市場控制台 | 把不同可信度的數字混在一起 | 每頁標段與證據等級 |
| **Claude 控制中心** | **agent 停下來等你而你不知道；在看錯 session 的情況下按了「允許」** | **等你的數量** |

和其他專案最大的差別：這裡的畫面中央放的是**別人的介面**（Claude Code 的 CLI 原始輸出），我們的外框不能和它搶。

## 1. 四條專屬規則（這次的創新）

### 規則一：顏色只回答「球在誰手上」

一眼掃過畫布，只需要知道每個 session 現在該誰動。

| 球在誰手上 | 顏色 | 狀態（符號、繁中、English） |
|---|---|---|
| **你** | 琥珀 `--you` `#f2b33d` | ◆ 等你允許 Needs approval ／ ◇ 等你回覆 Needs reply ／ ▣ 等你審計畫 Plan review |
| **壞了，你也得來** | 紅 `--fault` `#f0665f` | ✕ 錯誤 Error ／ ⚠ 卡住 Stuck |
| **Agent** | 藍 `--agent` `#4aa3ff` | ● 工作中 Running ／ ◌ 啟動中 Starting ／ ⋯ 排隊中 Queued |
| **沒人能動（等額度）** | 洋紅 `--quota` `#e58be0` | ⧖ 額度用完 Rate limited |
| **結束或不在場** | 灰白 `--idle` `#c9d1d9` | ✓ 完成 Done ／ ⊘ 失聯 Offline（加斜紋，見規則四） |

- **每個狀態都有專屬符號與文字**，不只靠顏色。
- **每個狀態也有自己的顏色（GM 2026-11-08，同組狀態原本同色，很難分辨）。** 上表的組別色現在只決定外觀：你／故障／額度是實心膠囊，agent 是淡底描邊，結束是淡色；卡片外圈、等你的琥珀框、故障的紅框仍用組別色。各狀態色（`tokens.css` 的 `--s-<status>`，樣式在 `shared/styles/status.css` 的 `.s-<status>`）：

  | 狀態 | 色 | 狀態 | 色 |
  |---|---|---|---|
  | ◆ 等你允許 | 橘 `#ff9a3c` | ● 工作中 | 藍 `#4aa3ff` |
  | ◇ 等你回覆 | 黃 `#ffe14d` | ◌ 啟動中 | 靛 `#8b8cff` |
  | ▣ 等你審計畫 | 青 `#3dd5e0` | ⋯ 排隊中 | 粉紅 `#ff7eb6` |
  | ✕ 錯誤 | 紅 `#f0665f` | ⧖ 額度用完 | 洋紅 `#e58be0` |
  | ⚠ 卡住 | 棕 `#d4a373` | ✓ 完成 | 白 `#f2f5f8` |
  |  |  | ⊘ 失聯 | 灰 `#8b949e` |

- 藍色是語意色，所以母規範拿藍色表示的「選中、主按鈕、焦點」改成**白色**（同美股、外匯）。
- **整個介面沒有綠色**。「上線」用白點。綠和紅只有一個例外：審核中心的 diff 區塊（`--diff-add` `--diff-del`，一定配 `+` `−`）。
- 「額度」相關一律洋紅：額度用量條 ≥ 85% 時、耗額度晶片（規則三之二）。

**實測**（WCAG 對比以 `--surface #14181f` 為底；ΔE76 用 Machado 2009 severity 1.0 模擬）

| 配對 | 正常 | 紅色盲 deutan | 綠色盲 protan | 藍色盲 tritan |
|---|---|---|---|---|
| agent ↔ you | 119.9 | 123.6 | 116.0 | 76.8 |
| agent ↔ fault | 98.0 | 93.6 | 70.2 | 111.5 |
| agent ↔ quota | 50.3 | 32.9 | **12.5** | 72.9 |
| you ↔ fault | 55.7 | 32.5 | 51.6 | 38.8 |
| you ↔ quota | 100.9 | 91.3 | 103.7 | **17.4** |
| fault ↔ quota | 60.9 | 62.2 | 57.7 | 41.9 |

對比：agent 6.76、you 9.57、fault 5.74、quota 7.71、idle 11.53，全部 ≥ 4.5:1。
**選色經過**：第一版額度用紫 `#a68bff`，和藍色在紅色盲下 ΔE 只有 2.8，幾乎分不開，改成洋紅。最差的 12.5 仍偏低，靠符號（● vs ⧖）當第二編碼。

### 規則二：放手線 — 左邊的線型回答「你放手了多少」

看錯權限模式就像海龜看錯模擬盤和實盤。每張卡左邊一條線，線越實，agent 越能不問你就動手。用線型不用顏色（延伸加密控制台的「越接近錢，線越實」）：

| 線型 | 模式 | 官方文件：不經詢問會執行什麼 |
|---|---|---|
| 點線 3px | `plan`、`dontAsk` | plan：只讀（auto 可用時加上分類器核可的指令）。dontAsk：只有事先允許的，**其餘自動拒絕** |
| 虛線 3px | `default` | 只讀，其他每步問你 |
| 實線 3px | `acceptEdits` | 讀、改檔、常見檔案指令 |
| 實線 5px | `auto` | 全部，有背景安全檢查 |
| **實線 5px、紅色** | `bypassPermissions` | **全部，不檢查** |

- 線旁邊一定有模式晶片，寫出模式名稱。
- `bypassPermissions` 等同海龜的「實盤」：紅線＋紅框晶片「略過權限」，在卡片、審核卡、新增 session 預覽都看得到。**這是紅色唯一不代表故障的地方，但它同樣表示要小心。**

### 規則三：終端機是別人的；會花額度的按鈕要自己說

**三之一：終端機裡面不碰。** 派工單的核心原則是畫面和原生 CLI 一模一樣。
- 狀態、按鈕、徽章一律在 xterm **外框之外**，絕不疊在終端機內容上。
- xterm 主題背景用 `--term-bg`（等於 `--bg`），16 色 ANSI 用 xterm 預設，不套品牌色。
- 摘要卡的「最後 4 行」是**去除 ANSI 的純文字**，用 `--fg-muted` 等寬字：縮小時不該有一片花色和狀態燈搶注意力。

**三之二：耗額度要標。** 中控台本身不花額度，所以少數會讓 session 花額度、又不像是在下指令的按鈕，要自己講：**◈ 耗額度**（洋紅晶片）貼在按鈕旁。目前有：「請隊長拆解」、開啟自動交接規則。

### 規則四：看不到的就是看不到

- **機器失聯**：卡片凍結在最後畫面，整張 45% 淡化＋灰色斜紋，寫「⊘ 失聯・最後讀到 HH:MM」。不把舊資料當現況（母規範的資料過期，縮小到單張卡）。
- **判斷不出來就寫工作中**（派工單 §4）：不用任何燈號表達猜測。
- **每張卡都有時間**：等你的卡寫「等了 12 分」，工作中的卡寫「3 秒前有輸出」。超過 10 分鐘沒輸出自然變成 ⚠ 卡住。

## 2. 設計邏輯（為什麼長這樣）

| # | 邏輯 | 畫面上的做法 |
|---|---|---|
| 1 | **一個主角：等你幾個** | 頁首固定「等你 3」26px＋主按鈕「下一個等我的 N」。其他數字都比它小。0 個時寫「沒有等你的」，不留空 |
| 2 | **按「允許」之前先確認呼號** | 審核卡最上方永遠是呼號 `機器 / 專案 @ 分支`（等寬）＋模式晶片＋放手線，再來才是工具與 diff。手機同樣，不省略 |
| 3 | **等最久的排最前** | 待處理清單與「下一個等我的」順序：⛔ 命中危險指令 → ✕ ⚠ 故障 → ◆ ▣ ◇ 依等待時間由久到短 |
| 4 | **縮放是語意的** | 畫布縮放 < 90%：摘要條；≥ 90% 或點兩下：真的 xterm。兩者同一個外框、同一個位置，不跳動 |
| 5 | **靜止時要安靜** | 全部工作中的畫布應該幾乎沒有亮色。亮度留給要你處理的東西：等你的卡 2px 琥珀框，其他 1px `--border` |
| 6 | **危險操作要多一道** | 允許命中危險清單的指令：按兩次（第一次顯示指令全文）。拒絕、要求修改：原因必填。全隊停止：按兩次。不用原生 confirm |
| 7 | **一切留痕** | 送入終端機的指令與核准／拒絕都進 audit_log；操作結果 `.msg` 緊貼按鈕 |
| 8 | **四種狀態都有畫面** | 載入中、空的（寫下一步：「按『新增 session』開始」）、錯誤、資料過期（hub 連不上時整頁淡化＋一行字，內容凍結） |

## 3. 資訊架構

```
頁首（sticky、半透明＋8px 模糊）
  Agent Board   [等你 3] [下一個等我的 N]      ● 2 台上線  ◈ 額度 62%     [新增 session]
  畫布 ｜ 待處理 ｜ 審核中心 ｜ 團隊 ｜ 設定          ← 選中＝白色 2px 底線
主區（畫布滿版，不套 1320px 上限；其他分頁主內容最寬 1320px）
  左側欄 232px，可收合：機器（上線／失聯、CPU／RAM／GPU）→ 額度 → 狀態圖例
  畫布：航班條、團隊框、交接虛線、便利貼；右下小地圖與縮放
手機（≤ 640px）：只有收件匣，只列等你的項目；複雜操作寫「回電腦處理」
```

骨架：母規範的**頂部分頁型**，畫布例外滿版。

## 4. 色彩

背景、表面、文字、邊框、間距、圓角、字級照母規範。只寫差異：

| Token | 色碼 | 用途 |
|---|---|---|
| `--accent` | `#ffffff` | 選中底線、主按鈕底；**不是藍色** |
| `--on-accent` | `#0a0c10` | 只用在白色主按鈕上的字 |
| `--accent-bg` | `rgba(255,255,255,.10)` | 選中的淡底 |
| `--ring` | `rgba(255,255,255,.6)` | 焦點外框 |
| `--you` | `#f2b33d` | 球在你手上 |
| `--fault` | `#f0665f` | 故障、`bypassPermissions`、危險按鈕 |
| `--agent` | `#4aa3ff` | 球在 agent 手上 |
| `--quota` | `#e58be0` | 額度 |
| `--idle` | `#c9d1d9` | 完成、失聯 |
| `--hatch` | 白 9% 斜紋 | 失聯、未開始 |
| `--diff-add` / `--diff-del` | `#46c26a` / `#f0665f` | **只在 diff 區塊**，一定配 `+` `−` |
| `--term-bg` | `#0a0c10` | xterm 背景 |
| `--canvas-dot` | `#1b212b` | 畫布點陣 |

**團隊框色**（使用者選，避開狀態色）：青 `#3cc4b0`、萊姆 `#a8c957`、靛 `#8b93f5`、杏 `#e8a87c`，2026-11-06 加冰 `#75e5f0`、沙 `#f4ec9a`、梅 `#a8578f`、堇 `#7d5fc7`（id：teal、lime、indigo、apricot、ice、sand、plum、violet；資料庫存 id，不認得的當 teal）。一律 1px 框＋8% 底＋名稱標籤，不只靠顏色。介面只有深色主題，色碼只有一組。

實測（Machado 2009 severity 1.0，CIEDE2000／括號內 ΔE76；8 色兩兩取最小）：

| | 正常 | protan | deutan | tritan |
|---|---|---|---|---|
| 團隊色之間最小 | 14.4 萊姆/沙（21.6） | 10.6 梅/堇（17.6） | **5.5** 萊姆/杏（15.5） | 9.0 青/冰（13.5） |
| 團隊色對狀態色最小 | 14.0 靛/agent（19.0） | 2.6 靛/agent（3.9） | 1.5 靛/agent（5.7） | 2.6 杏/you（3.9） |

- 新增的 4 色沒有拉低原本 4 色的色盲下限（最差 5.5 是原本的萊姆/杏）。新色對狀態色在正常視覺下 ΔE00 都 ≥ 18.8（沙/you），對比 `--surface` ≥ 3:1（梅 3.75、堇 3.67，只用在框線與色塊，文字用 `--fg-muted`）。
- 團隊色對狀態色在色盲下會接近（最差是原本的靛和 agent 藍），所以團隊框一定配名稱標籤，狀態一定配符號。
- 選色方法：排除綠色與低彩度（和 idle 灰混淆），正常視覺對狀態色 ΔE00 ≥ 18、Lab 彩度 ≥ 30，再挑讓四種模擬下團隊色之間最小 ΔE 最大的。

**用量條**：CPU／RAM／GPU／context 用 `--agent`，≥ 60% `--you`，≥ 85% `--fault`。額度條用 `--quota`，≥ 85% 加 ⚠。

## 6. 文案

介面支援繁中與英文，**兩種語言都用固定詞**：

| 繁中 | English | 繁中 | English |
|---|---|---|---|
| 等你 | Waiting on you | 下一個等我的 | Next up |
| 允許一次 | Allow once | 允許並記住 | Always allow |
| 拒絕 | Deny | 要求修改 | Request changes |
| 批准計畫 | Approve plan | 交接 | Hand off |
| 上線 | Online | 失聯 | Offline |
| 耗額度 | Uses quota | 略過權限 | Bypass permissions |

- 按鈕寫動詞，不寫「確定」。錯誤寫「發生什麼＋怎麼辦」：「連不到 demo-studio，恢復後會自動接回」。
- 時間寫相對值（「等了 12 分」），提示框顯示完整時間。
- `session`、`worktree`、`hook` 這類專有名詞中文介面也不翻。

## 7. 和兄弟專案不一樣的地方

| | 海龜訊號 | 美股平台 | 外匯模組 | **Claude 控制中心** |
|---|---|---|---|---|
| 顏色語意 | 漲跌、好壞 | 判決藍／橙 | 藍流進／橘流出 | **球在誰手上** |
